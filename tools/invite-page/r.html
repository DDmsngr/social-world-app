Код приглашения

Скачать ChaWo Уже установлено — открыть
  1. Нажмите «Скачать ChaWo» и установите файл (Android может попросить разрешение на установку).
  2. Откройте ChaWo и войдите — код подставится сам.
  3. Не подставился — введите его в «Пригласить в ChaWo» → «Ввести код пригласившего».

Пока приложение есть только для Android.
