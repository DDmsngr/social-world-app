# Стикеры: паки для магазина ChaWo

Каталог стикеров живёт на сервере (миграция `0078_sticker_store.sql`):
таблицы `sticker_packs`, `stickers`, `sticker_families`, коллекции
пользователей — `user_sticker_packs`, картинки — публичный бакет `stickers`.
Приложение берёт каталог одним вызовом `sticker_catalog()` и в сборку стикеров
не вшивает.

Источник паков — эта папка:

```
packs/
  families.json          семейства эмоций для поиска («любовь» → love)
  <пак>/pack.json        название, описание, издатель, категория, статус,
                         порядок в магазине, версия, стикеры по порядку
  <пак>/<ключ>.webp      512×512, прозрачный фон
```

## Добавить пак

1. Нарисовать лист на плоском фоне (маджента `#FF00FF`) и нарезать:
   `cut.py` (лист 7×5, по образцу `packs.example.json`) или свой скрипт по
   образцу `add_alexa.py` (лист 6×4, чистит розовую кайму и обломки соседних
   ячеек, пишет `packs/<пак>/`).
2. В `packs/<пак>/pack.json` — шапка пака и для каждого стикера `key`,
   `title`, `emoji`, `synonyms`, `emotions` (семейства из `families.json`).
   `status`: `draft` — не виден никому, `published` — в магазине,
   `archived` — снят с публикации.
3. Проверить без сети: `python -I publish_packs.py --check`.
4. Опубликовать: `powershell -File tools\stickers\publish.ps1 [пак]` — ключ
   сервера читается по ssh и не выводится. Файлы перезаписываются, строки
   обновляются по id; запуск можно повторять.

## Правила

- Id стикера `<пак>.<ключ>` уходит в сообщения навсегда: ключ не
  переименовывать. Убрать стикер нельзя (база отклонит удаление,
  `publish_packs.py` — пропажу строки): пак снимают с публикации, и старые
  сообщения продолжают его показывать.
- Телефоны кешируют картинку по адресу: перерисованный файл под тем же ключом
  до многих дойдёт не сразу. Существенно другой рисунок — новый стикер с
  новым ключом. `version` в `pack.json` пока только учёт.
- Публиковать паки может только сервер: у пользователей нет прав на запись
  ни в таблицы каталога, ни в бакет (проверки — `supabase/tests/stickers.sql`).

Поиск: слово сворачивается до основы («любовь», «любви», «люблю»), совпадение
по названию важнее синонимов, синонимы важнее семейства эмоции. Логика — в
`lib/features/chat/domain/stickers.dart`, проверки — в
`test/features/chat/stickers_test.dart`.
