# Стикеры: нарезка листов и теги поиска

Фирменные стикеры рисуются нейросетью листом 7×5 на плоском фоне (маджента
`#FF00FF`), потом режутся здесь на отдельные WebP 512×512 с прозрачностью и
кладутся в `assets/stickers/` вместе с `manifest.json`.

| Файл | Что делает |
|---|---|
| `cut.py` | Вырезает фон, чистит кромку от цветной каймы, раскладывает стикеры по ячейкам сетки, масштабирует пак одним коэффициентом (относительные размеры сохраняются), пишет превью на светлом и тёмном фоне |
| `tags.py` | Для каждого стикера: название, синонимы, семейства эмоций (первое — главное) и эмодзи-заменитель. По этим словам работает поиск в приложении |
| `export_app.py` | Кладёт нарезку в `assets/stickers/<пак>/<ключ>.webp` и собирает `manifest.json` |

```bash
pip install numpy pillow scipy opencv-python-headless
python3 -I cut.py packs.json            # packs.json — по образцу packs.example.json
python3 -I export_app.py out ../../assets/stickers
```

Id стикера (`<пак>.<ключ>`, например `chao.wave`) уходит в сообщения и **не
меняется**: переименовать ключ — значит сломать уже отправленные стикеры
(вместо картинки покажется эмодзи-заменитель). Новый стикер — новый ключ.

Поиск: слово сворачивается до основы («любовь», «любви», «люблю»), совпадение
по названию важнее синонимов, синонимы важнее семейства эмоции. Логика — в
`lib/features/chat/domain/stickers.dart`, проверки — в
`test/features/chat/stickers_test.dart`.
