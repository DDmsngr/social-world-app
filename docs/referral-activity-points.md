## Требования

**Цель.** Органический рост: пользователи зовут реальных людей из окружения. Программа связана с Activity Points и персональным QR-кодом.

**Идентификатор.** У каждого пользователя уникальный referral ID → персональная ссылка (пример `chawo.app/r/7F82K9`), QR-код, deep link, своя реферальная цепочка. QR и ссылка не содержат персональных данных.

**Уровни.** 5 уровней: 100 / 50 / 25 / 15 / 10 Activity Points, максимум 200 за одного активированного пользователя. После 5-го уровня начислений нет (A→B→C→D→E→F→G: при G получают F 100, E 50, D 25, C 15, B 10, A — 0). Все значения настраиваются на backend.

**Активированный реферал** — не просто регистрация: зарегистрирован по приглашению, подтвердил телефон, создал аккаунт, выполнил минимальные условия активации. Условия настраиваются на backend без обновления приложения (пример: телефон, основные данные профиля, открыл Pulse, первое целевое действие).

**Экран «Пригласить в ChaWo»** (Профиль → Пригласить в ChaWo): заголовок «Приглашай друзей в ChaWo», подзаголовок «Приглашай людей, создавай свою сеть и получай Activity Points», большой QR, «Моя ссылка», кнопки «Поделиться» и «Скопировать». Статистика: приглашено напрямую, всего в сети, заработано на приглашениях; разбивка по уровням 1–5. История приглашений: пользователь, дата, уровень, статус (ожидает активации / активирован / отменён / проверяется), баллы.

**Сценарии QR/ссылки.**
- Приложение не установлено: реферальная страница → сохранить referral ID → магазин → после установки и регистрации связать с пригласившим.
- Установлено: открыть приложение сразу, передать referral ID, связать после регистрации.
- iOS Universal Links, Android App Links, deep links. Ссылка работает из любого канала (QR, Telegram, WhatsApp, Instagram, SMS, email, копирование).
- referral ID не теряется при переходе в магазин, установке, первом запуске, авторизации, повторном открытии.

**Пригласивший.** Ровно один непосредственный; после подтверждения связи сменить нельзя. Цепочка строится автоматически до 5 уровней вверх.

**Статусы начисления:** Pending, Confirmed, Cancelled, Reversed, Suspicious.

**Ожидание и подтверждение.** После активации начисление «+100, ожидает подтверждения», не окончательное. Баланс: Доступно / Ожидает подтверждения / Всего. Период проверки (например 24 ч) настраивается; после проверки Pending → Confirmed. Не выполнил условия в срок → обратная операция −100 «Реферал не выполнил условия активации. Начисление отменено», исходная → Cancelled. После подтверждения при выявлении бота/фейка/накрутки — отдельная операция списания (Reversed), при необходимости пересчёт по цепочке.

**Антифрод.** Анализ совокупности признаков: телефон, устройство, IP, частота регистраций, повторяющиеся устройства, удаление и повторная регистрация, одинаковые паттерны, массовое создание, подозрительная активность. Не блокировать по одному совпадению. Запрет саморефералов: себя, свои доп. аккаунты, повторная регистрация удалённого, свои ссылки, искусственные цепочки.

**Приватность.** Пользователи 2–5 уровней не раскрываются (если не друзья / не доступны по настройкам). Сеть — для расчёта, не публичный список контактов.

**Уведомления.** Новый бонус (+100), бонус 2–5 уровня («Ваш реферал пригласил нового пользователя, +50»), подтверждение, отмена. Отключаются в настройках. Тап по уведомлению открывает операцию в истории.

**Экран Activity Points** (тап по баллам в профиле): Доступно / Ожидает / Всего; полная история (начисления, списания, ожидающие, подтверждённые, отмены, реферальные, будущие источники): баллы со знаком, дата, время, источник, уровень, статус, причина. Группировка по дням. Фильтры: Все / Начисления / Списания (позже Рефералы / Активность / Другое). Детальная карточка операции; списание связано с исходным начислением.

**Журнал.** Баланс только через транзакции, без «просто поменять число». Коды операций вида `referral_level_1_pending`, `referral_level_3_confirmed`, `referral_activation_expired`.

**Админка.** Вкл/выкл программы, число уровней, баллы уровней, условия активации, период ожидания, срок активации, период проверки, лимиты, антифрод-параметры, ручная отмена начислений.

**Аналитика (события).** referral_link_created, referral_qr_opened, referral_link_opened, referral_store_redirect, referral_app_opened, referral_registration_started, referral_registered, referral_phone_verified, referral_activation_started, referral_activated, referral_reward_pending, referral_reward_confirmed, referral_reward_cancelled, referral_reward_reversed, referral_fraud_detected, activity_points_opened, activity_points_transaction_opened.

## Что уже есть в коде

- `profiles.social_score` + журнал `score_events` (profile_id, reason, delta) с триггером пересчёта — уже ledger-модель. Activity Points логично строить на нём (переименование в UI или расширение журнала статусами), а не заводить второй счёт.
- `referral_codes` / `referral_signups` (0025) — коды **мест** для бизнеса («Ввести код места»), не персональные. Персональные коды — новая сущность, нужно не смешать.
- Вход — VK ID / Яндекс ID / почта. **Подтверждения телефона нет.**
- APK раздаётся напрямую (GitHub-зеркало), **не через Google Play**; Apple-аккаунта нет.
- Домена `chawo.app` нет (решение 19.09: домен не покупать до ясности с названием).
- Системы аналитики нет.
- Админка — Team Workspace на сайте (`/dashboard`), туда можно добавить настройки программы.
