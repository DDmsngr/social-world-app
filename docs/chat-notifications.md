# Чаты: быстрые настройки уведомлений

Заметки брейншторма (30.09). Кода нет, делать только по команде.

Цель: в пару касаний прямо из чата выбрать, как он будет беспокоить: со звуком, только вибрацией, тихо, только в рабочее время, выключить на время.

---

## 0. Как сейчас устроены пуши и что из этого следует

- Сообщение → триггер в базе → Edge Function `push-send` → FCM (`supabase/functions/push-send/index.ts`).
- FCM отправляется как **notification-сообщение** (`notification: {title, body}` + `android.notification.channel_id`). Когда приложение свёрнуто или закрыто, уведомление **показывает сама система**: наш код на телефоне его не видит и отфильтровать не может.
- Поэтому **решать «беспокоить или нет» нужно на сервере**, в `push-send`, для каждого получателя. Иначе «только в рабочее время» будет работать лишь при открытом приложении.
- **Звук и вибрация в Android задаются каналом** уведомлений, и после создания канала приложение поменять их не может. Значит, режимы — это **разные каналы**, а сервер выбирает `channel_id` под настройку получателя.
- **iOS:** «только вибрация» отдельно от звука нет, телефон вибрирует по своим системным настройкам. Там режимы такие: со звуком / тихо (без `sound`) / выключено. В интерфейсе iOS пункт «Только вибро» заменяем на «Тихо».
- Системный «Не беспокоить» телефона работает поверх наших настроек сам.

## 1. Что может человек

### 1.1. Быстро, из чата — одна шторка

Как открыть:
- **колокольчик в шапке чата** (рядом со щитом шифрования); значок показывает текущий режим: 🔔 / 📳 / 🔕;
- **долгий тап по чату в списке** → «Уведомления».

Шторка:

```
Уведомления: levberton

  ◉ Со звуком
  ○ Только вибрация          (на iOS — «Тихо»)
  ○ Тихо — только в шторке
  ○ Выключить

  Выключить на:  [1 час] [8 часов] [До утра] [1 день] [Навсегда]

  Расписание
  ○ Всегда
  ○ Только в рабочее время    Пн–Пт, 9:00–18:00  ›
  ○ Кроме ночи                23:00–8:00  ›

  ☑ Показывать текст сообщения в уведомлении
  ☑ Упоминания и ответы мне — всегда   (только в группах)
```

- Изменения применяются сразу, без кнопки «Сохранить».
- «Выключить на…» сверху показывает остаток: «Без уведомлений до 18:40 · Включить».
- Время рабочих часов и ночи — одно касание по строке → выбор дней и часов.

### 1.2. Глобально — «Настройки → Уведомления»

Настройки по умолчанию **отдельно** для:
- личных чатов,
- групп,
- чатов квестов,
- активности (лайки, комментарии, подписки).

Плюс **общие тихие часы** (например 23:00–8:00 для всего приложения) и переключатель «Показывать текст сообщений в уведомлениях».

Настройка конкретного чата **перекрывает** настройку по умолчанию. В шторке чата вверху пометка: «Своя настройка · Сбросить к общей».

### 1.3. Видно в списке чатов

- У выключенного чата — 🔕 рядом с временем, счётчик непрочитанных **серый**, а не цветной.
- У чата с расписанием вне рабочего времени — маленький 🌙.

## 2. Логика: пришло сообщение — что делать

Для каждого получателя `push-send` вычисляет:

```
1. Чат выключен навсегда или muted_until > сейчас     → не отправлять
   (кроме: группа + упоминание/ответ мне + «упоминания всегда»)
2. Расписание чата (или общее по типу чата):
   сейчас вне разрешённого окна в поясе получателя     → не отправлять
3. Общие тихие часы, и чат не в исключениях            → отправить тихо (канал silent)
4. Иначе                                               → отправить в канал по режиму:
      sound → messages, vibrate → chat_vibrate, silent → chat_silent
5. «Показывать текст» выключен                         → body = «Новое сообщение»
```

- **Не отправили пуш ≠ потеряли сообщение.** Сообщение в чате, счётчик непрочитанных растёт. Когда окно откроется, прошедшие уведомления **не досылаем** пачкой: утром 30 пушей за ночь хуже, чем ни одного. Вместо них — одно сводное «5 новых сообщений в 2 чатах» (этап 2, по желанию).
- **Часовой пояс получателя** хранится в профиле (`profiles.timezone`, берётся с телефона при входе и при смене). Иначе «9–18» посчитаются по времени сервера.
- **Расписание через полночь** («кроме ночи 23:00–8:00») считается правильно — это тоже в тестах.
- В личных чатах текст пуша и так не раскрывается (сообщения зашифрованы), так что «показывать текст» касается групп и квест-чатов.

## 3. Данные

```sql
create table chat_notification_prefs (
  profile_id      uuid not null references profiles on delete cascade,
  -- null = настройка по умолчанию для типа чата
  conversation_id uuid references chat_conversations on delete cascade,
  chat_kind       text check (chat_kind in ('direct', 'group', 'quest')),
  mode            text not null default 'sound'
                  check (mode in ('sound', 'vibrate', 'silent', 'off')),
  muted_until     timestamptz,              -- «выключить на…»
  schedule        jsonb,                    -- {"days":[1..5],"from":"09:00","to":"18:00"}
  show_preview    boolean not null default true,
  mentions_bypass boolean not null default true,
  updated_at      timestamptz not null default now(),
  check ((conversation_id is null) <> (chat_kind is null))
);
-- уникальность: одна строка на (profile, conversation) и одна на (profile, chat_kind)

alter table profiles
  add column timezone text,                 -- 'Europe/Moscow'
  add column quiet_hours jsonb;             -- общие тихие часы
```

- RLS: только свои строки.
- `my_chats()` отдаёт по каждому чату `mode` и `muted_until`, чтобы список рисовал 🔕 без отдельного запроса.
- В `push-send` — один запрос настроек на всех получателей сразу, а не по одному.

**Каналы Android** (создаются при первом запуске, `push_service.dart`):

| id | Название в настройках Android | Звук | Вибрация |
|---|---|---|---|
| `messages` (уже есть) | Сообщения | да | да |
| `chat_vibrate` | Сообщения — только вибрация | нет | да |
| `chat_silent` | Сообщения — тихо | нет | нет |
| `activity` | Активность (уже есть) | | |

Существующий канал `messages` не переименовываем: иначе у людей сбросятся настройки, которые они уже поменяли в Android. Он и есть режим «со звуком».

## 4. Тесты

**Логика решения — чистая функция в `push-send`** `decide(prefs, defaults, profile, message, now)` → `skip | {channel, showPreview}`. Тесты — `deno test`:

- режим `off` → skip;
- `muted_until` в будущем → skip; в прошлом → отправляем;
- упоминание в группе при выключенном чате и `mentions_bypass` → отправляем; в личном чате этот обход не работает;
- рабочие часы Пн–Пт 9–18: вторник 10:00 → да; вторник 19:00 → skip; суббота 12:00 → skip;
- ночь 23:00–8:00: 23:30 и 07:59 → skip, 08:00 → да (граница через полночь);
- пояс: 10:00 по Москве и 10:00 по Владивостоку — один и тот же момент UTC даёт разные решения;
- своя настройка чата перекрывает настройку по типу; сброс → снова по типу;
- общие тихие часы → канал `chat_silent`, а не skip;
- `vibrate` для iOS-токена → без звука (тихо);
- `show_preview = false` → тело «Новое сообщение».

**Flutter:**
- шторка: выбор режима сразу вызывает сохранение; «на 1 час» показывает «до ЧЧ:ММ»;
- список чатов: 🔕 и серый счётчик у выключенного чата;
- на iOS вместо «Только вибрация» показан «Тихо».

**Руками на двух телефонах:** свёрнутое приложение, закрытое приложение, блокировка экрана — во всех трёх случаях режим соблюдается (именно это проверяет, что решение принимает сервер).

## 6. Открытые вопросы

1. «Рабочее время» по умолчанию — Пн–Пт 9:00–18:00?
2. Сводку «за ночь пришло N сообщений» утром — нужна?
3. Важные контакты, которые пробивают тихие часы и «выключено» (как «Избранные» в iOS) — нужны?
4. Настройки уведомлений синхронизируются между устройствами человека (да, раз решение на сервере) — ок, что нельзя сделать «на планшете тихо, на телефоне со звуком»?
