## Срочное, не дожидаясь фич

1. **Утечка GPS через EXIF** — фото уходят в публичный бакет с метаданными (`instagram-import-photo-calendar-geo.md`, раздел 0).
2. **Зависание отправки в чате после выключения VPN** — нет тайм-аута и понятной ошибки (`chat-message-menu.md`, раздел 5).

## Открытые вопросы на завтра

**Гео и перенос**
- Где хранить точную точку съёмки: A (таблица «только автор»), B (только на устройстве), C (зашифрованно).
- Тексты согласия и инструкции — к юристу.
- Длинные видео при переносе: пропускать или обрезать.

**Знакомство**
- Бонусы по QR: условия, кто задаёт, как кассир отмечает выдачу — **обсудить с Левоном**.
- Код места через установку из стора (Google Play / RuStore) — проверить.

**Чаты**
- Владелец группы удаляет чужие сообщения у всех — да?
- `emoji_picker_flutter` для панели эмодзи — ок?
- Скрывать нижнюю панель при открытой клавиатуре — ок?
- Реакции в личных чатах хранить открыто (метаданные) — ок?

**Уведомления**
- Рабочее время по умолчанию Пн–Пт 9–18?
- Утренняя сводка «за ночь N сообщений» — нужна?
- «Важные контакты», пробивающие тихие часы — нужны?
- Настройки одни на все устройства — ок?

**Стикеры**
- Кто рисует фирменный пак, стиль, сколько стикеров.
- Порог жалоб для снятия пака с витрины (предложение: 3 от разных аккаунтов старше 3 дней).
- Сомнительные по ИИ паки — ждут человека или публикуются?
- Кто модератор на старте.
- Подборки и категории магазина на старте.
- Где работает ИИ-модерация (российское облако или своя модель).
